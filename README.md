# Легенды подземелий · версия 1.6 «Пакт силы»

Патч собран поверх версии 1.4 «Арсенал». Исправлен расчёт Пакта силы Еретика и принудительно обновлён кэш приложения.

## Главное исправление

- Пакт силы теперь считается как `(базовая Сила + бонус от порчи + 2) × 2`.
- Нулевая порча даёт Силу +4; одна порча — +6; две порчи — +8.
- Пересчёт выполняется сразу при нажатии, до сохранения в Firestore.
- Добавлена совместимость со старыми вариантами сохранённого названия пакта.
- Урон оружия от Силы обновляется тем же расчётом.
- На выбранном Пакте силы постоянно показывается текущая Сила, чтобы эффект был виден сразу.

## Что входит из версии 1.4

- Нажимаемый блок брони на каждой карточке.
- Каталог оружия и снаряжения с поиском и разделами.
- Класс брони считается автоматически.
- Щит автоматически добавляет +2 к КБ.
- Серво-броня открывает третью руку.
- Оружие и предметы используют общий лимит рук.
- Два одинаковых оружия можно взять, если хватает рук.
- Расходники можно добавлять несколько раз.
- Постоянное снаряжение, например щит или силовое поле, нельзя добавить дважды.
- Когти Еретика появляются автоматически, не занимают рук и не снимаются.
- Урон оружия показывает актуальную характеристику. Порча и Пакт силы сразу меняют подпись урона.
- Нажатие на выбранный предмет открывает его правило и красную кнопку снятия.
- Нажатие вне окна закрывает его.
- Арсенал сохраняется в Firestore и виден после входа с другого устройства.
- В карточке сопартийца отображаются его броня, оружие и снаряжение.

## Правила рук

Обычный персонаж имеет 2 руки. Серво-броня даёт 3 руки.

Оружие и снаряжение используют общий лимит. Предметы, в описании которых не указано занятие руки, используют 0 рук.

Если новая броня уменьшает число рук ниже уже занятого значения, выбрать или снять её нельзя, пока игрок не освободит руки.

## Файлы

- `arsenal.js` — полный каталог брони, оружия и снаряжения.
- `app.js` — выбор, снятие, руки, КБ, урон и сохранение.
- `build.py` — генератор всех восьми карточек и окон арсенала.
- `app.css` — оформление карточки и окон каталога.
- `lobby-store.js` — показывает снаряжение сопартийцев.
- `sw.js` — новый кэш `legendy-v10-pact-strength-correct`.

## Установка патча

1. Распакуйте архив.
2. Загрузите все файлы в корень репозитория GitHub с заменой старых.
3. Нажмите `Commit changes`.
4. Firestore Rules повторно публиковать не нужно: правила базы не менялись.
5. Откройте сайт с параметром `?v=pact-strength-3`.

Пример:

`https://kithoone.github.io/legens.github.io/?v=pact-strength-3`

Если сайт установлен на главный экран, полностью закройте его после обновления и откройте снова.

## Редактирование каталога

Новые предметы добавляются в `arsenal.js`. Разметку карточек вручную менять не нужно.

Тексты архетипов по-прежнему находятся в `build.py`. После правки запустите:

```bash
python build.py
```

После пересборки загрузите новый `index.html` на GitHub.
