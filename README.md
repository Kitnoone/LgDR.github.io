# Легенды подземелий — v1.7 «Оружие Фанатика смерти»

Патч собран поверх v1.6 и сохраняет арсенал, лобби, облачное хранение и исправленный Пакт силы.

## Добавлено

- **Кинжалы фанатика** — `2d4 + Сила`, занимают 2 руки.
- **Арбалет фанатика** — `d4 + Ловкость`, занимает 1 руку.
- Оба вида оружия доступны только архетипу **Фанатик смерти** (`cultist`).

## Жёсткое ограничение оружия

Фанатик смерти выбирает только один оружейный комплект и видит в арсенале только:

1. Кинжалы фанатика.
2. Арбалет фанатика.

Одновременно можно выбрать только один из этих вариантов. Любое другое оружие для него недоступно. При загрузке старого сохранения или смене персонажа несовместимое оружие автоматически снимается. Культовое оружие Фанатика также не переносится к другим архетипам.

1. Загрузите все 15 файлов в корень GitHub-репозитория с заменой старых.
2. Нажмите **Commit changes**.
3. Firestore Rules повторно публиковать не нужно.

`https://kithoone.github.io/legens.github.io/?v=fanatic-weapons-1`
