# Легенды подземелий — версия с лобби

В этой сборке уже есть:

- Firebase Authentication: регистрация и вход по почте и паролю;
- Cloud Firestore: постоянное хранение персонажа и снаряжения;
- командные лобби по шестизначному коду;
- от 3 до 8 активных участников;
- общие монеты и порча в реальном времени;
- горизонтальная строка сопартийцев наверху;
- карточка сопартийца с архетипом, здоровьем, ролью и подсказками;
- командные уведомления о порче, монетах, ультимейтах и наградах Сестры;
- повторяющиеся архетипы разрешены.

## Как работает минимум 3

Лобби можно создать одному человеку, иначе собрать его было бы невозможно.

- 1–2 участника: лобби имеет статус «Формируется», общие ресурсы заблокированы;
- 3–7 участников: команда активна;
- 8 участников: команда заполнена, девятый войти не сможет.

## Уникальный бонус к порче

Если в команде есть хотя бы один Неофит с **Проклятым основанием**, любое положительное получение порчи добавляет ещё 1 порчу. Этот бонус проверяется на уровне всей команды и **не складывается**, даже если Проклятое основание выбрали несколько Неофитов.

Активные применения разных способностей остаются отдельными действиями. Например, два Еретика могут по отдельности применить свои «Дары тьмы», но за каждое конкретное получение порчи уникальный командный бонус прибавляется не более одного раза.

## Структура Firestore

- `characters/{uid}` — личное состояние персонажа;
- `teams/{CODE}` — состав лобби, монеты, порча и последние события.

Обновления монет и порчи выполняются Firestore-транзакциями, чтобы одновременные нажатия с разных телефонов не перезаписывали друг друга.

## Обязательная настройка Firestore Rules

Откройте:

`Firebase Console → Firestore Database → Rules`

Полностью замените старые правила содержимым файла `firestore.rules` из этой папки и нажмите **Publish**.

Старые правила разрешают доступ только к `characters`. Без новых правил создание лобби завершится ошибкой доступа.

## Загрузка на GitHub Pages

Загрузите в корень репозитория все файлы из папки, кроме временной папки `__pycache__`, если она вдруг появилась.

После публикации откройте сайт с новым параметром, например:

`?v=lobby1`

В `sw.js` версия кэша уже повышена до `legendy-v4-lobby`.

## Проверка

1. Создайте три разных Firebase-аккаунта или войдите с трёх устройств.
2. На первом аккаунте откройте кнопку **Команда → Лобби** и создайте лобби.
3. Скопируйте шестизначный код.
4. На двух других аккаунтах войдите по коду.
5. После третьего участника кнопки порчи и монет разблокируются.
6. Измените монеты на одном телефоне — значение должно измениться у всех.
7. Нажмите имя сопартийца в верхней строке — откроются его архетип и подсказки.

## Файлы

- `build.py` — тексты карточек и сборщик `index.html`;
- `app.js` — игровая механика и адаптер командных ресурсов;
- `auth.js` — Firebase Authentication;
- `character-store.js` — облачное состояние персонажа;
- `lobby-store.js` — создание, вход, выход и синхронизация лобби;
- `firestore.rules` — правила доступа для персонажей и команд;
- `app.css` — мобильный интерфейс, лобби и печать;
- `sw.js` — офлайн-кэш файлов приложения.
