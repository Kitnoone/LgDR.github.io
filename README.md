# Легенды подземелий — v1.16 «HTML-сценарии мастера»

Патч собран поверх v1.15 и сохраняет арсенал, лобби, облачное хранение, ручную роль мастера и все предыдущие исправления.

## Добавлено

- **Кинжалы фанатика** — `2d4 + Сила`, занимают 2 руки.
- **Арбалет фанатика** — `d4 + Ловкость`, занимает 1 руку.
- Оба вида оружия доступны только архетипу **Фанатик смерти** (`cultist`).

## Жёсткое ограничение оружия

Фанатик смерти выбирает только один оружейный комплект и видит в арсенале только:

1. Кинжалы фанатика.
2. Арбалет фанатика.

Одновременно можно выбрать только один из этих вариантов. Любое другое оружие для него недоступно. При загрузке старого сохранения или смене персонажа несовместимое оружие автоматически снимается. Культовое оружие Фанатика также не переносится к другим архетипам.

## Установка

1. Загрузите всё содержимое папки патча в корень GitHub-репозитория с заменой старых файлов. Папку `assets/weapons/` необходимо сохранить целиком.
2. Нажмите **Commit changes**.
3. Firestore Rules повторно публиковать не нужно, если v1.15 уже установлена.
4. Откройте сайт:

`https://kithoone.github.io/legens.github.io/?v=gm-html-reader-1`

Кэш приложения: `legendy-v20-gm-html-reader`.

## v1.15 — кабинет мастера с ручной ролью

Добавлены `master.html`, `master.css`, `master.js` и `master-data.js`.

### Как назначить мастера вручную

1. Создайте или войдите в обычный аккаунт Firebase на сайте.
2. В Firebase Console откройте **Authentication → Users** и скопируйте UID нужного аккаунта.
3. Откройте **Firestore Database → Data**.
4. Создайте коллекцию `roles`.
5. Создайте в ней документ, идентификатор которого полностью совпадает с UID аккаунта.
6. Добавьте поле:
   - имя: `role`
   - тип: `string`
   - значение: `gm`
7. Опубликуйте новый файл `firestore.rules` из этой сборки.
8. Откройте `master.html` и войдите тем же аккаунтом.

Обычный клиент не может сам создать или изменить документ роли. Роль добавляется и удаляется только вручную через Firebase Console.

### Возможности кабинета

- список всех существующих лобби;
- просмотр порчи, монет и состава;
- здоровье, броня, оружие, урон, правила и снаряжение каждого игрока;
- количество потраченных зарядов способностей;
- роспуск лобби с сохранением личных персонажей;
- загрузка, поиск, чтение и удаление сценариев TXT/MD.

## v1.16 — HTML-сценарии и режим чтения

- Кабинет принимает `.html` и `.htm` вместе с TXT и Markdown.
- HTML открывается как готовая вёрстка внутри изолированного `iframe` без доступа к кабинету и данным Firebase.
- В сборку уже включён пример `assets/scenarios/prolog-verstka.html` — «Пролог — Аркона Прайм». Он автоматически отображается в библиотеке мастера и не требует загрузки в Firestore.
- Во время чтения сверху всегда остаётся панель мастера. Кнопка **Лобби** открывает боковое меню со всеми командами, порчей, монетами и числом игроков.
- Из этого меню можно открыть полную карточку лобби и посмотреть здоровье, броню, оружие, урон, снаряжение и использованные способности игроков, не закрывая сценарий.
- Максимальный размер загружаемого сценария остаётся 700 КБ.

## Патч v1.18 — портретный полуфейд и исправление шапок

Исправлено и улучшено:
- карточки выбора архетипов теперь используют более цельную баннерную компоновку, ближе к референсу: портрет встроен в правую часть карточки, а слева плавно уходит в полуфейд;
- шапки листов персонажей переделаны под тот же принцип: у каждого класса справа отображается портрет, который мягко проявляется от центра к правому краю;
- добавлены CSS-фолбэки на случай, если JavaScript не успел подставить портрет, поэтому изображения гарантированно видны и в выборе класса, и на самом листе;
- для каждого архетипа настроен собственный фокус кадра, чтобы в правой части баннера читались лицо и характер персонажа, а не случайный фрагмент иллюстрации;
- обновлён service worker и версия ресурсов, чтобы GitHub Pages и PWA не держали старый кэш.
