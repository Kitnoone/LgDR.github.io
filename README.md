# Legendi Lobby v1.33 — сглаживание коррапт-темы

Этот патч исправляет две визуальные проблемы прошлой версии:

1. Убирает резкие диагональные красные полосы в верхних панелях при высокой Порче.
2. Делает подложку под портретами в карточке персонажа и в меню выбора более плавной, полупрозрачной и органичной.

### Что изменено
- Смягчён градиент поверх портретов на карточке персонажа.
- Смягчён градиент поверх портретов в списке выбора персонажей.
- Ослаблены резкие декоративные линии в заражённой теме.
- На мобильных устройствах убраны агрессивные диагональные штрихи, оставлена мягкая демоническая виньетка.
- Обновлён service worker cache: `legendy-v37-slow-corruption-smoothing`.

### Установка
Замените файлы сайта содержимым архива. После загрузки откройте сайт и один раз обновите страницу без кэша.
